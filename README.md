# Durga Maa Sketching

An interactive digital artwork featuring Maa Durga, presented through an animated pencil-sketch and coloring sequence, Bengali lettering, and a 3D parallax effect.

## Live Demo

[View Durga Maa Sketching](https://soumyadip9575.github.io/Durga-Maa-Sketching/)

## Run Locally

Open `index.html` in a modern web browser with JavaScript and WebGL enabled. The project is self-contained and requires no package installation or build step.

## Technology

- HTML, CSS, and JavaScript
- Canvas 2D for drawing and coloring effects
- WebGL for 3D parallax

## Deployment

The site is published with GitHub Pages using the workflow in `.github/workflows/pages.yml`. Changes pushed to the `main` branch trigger a deployment.
