# Durga Maa Sketching

An interactive digital artwork featuring Maa Durga, presented through an animated pencil-sketch and coloring sequence, Bengali lettering, a 3D parallax effect, and an embedded Dhak mix.

## Live Demo

[View Durga Maa Sketching](https://soumyadip9575.github.io/Durga-Maa-Sketching/)

## Run Locally

Open `index.html` in a modern web browser with JavaScript and WebGL enabled. The Dhak mix starts automatically with the drawing; no separate audio file or player controls are needed. Browser autoplay policies may block sound until the visitor interacts with the page. The project is self-contained and requires no package installation or build step.

## Technology

- HTML, CSS, and JavaScript
- Canvas 2D for drawing and coloring effects
- WebGL for 3D parallax
- Embedded MP3 audio for the Dhak mix

## Deployment

The site is published with GitHub Pages using the workflow in `.github/workflows/pages.yml`. Changes pushed to the `main` branch trigger a deployment.
